# The Excuse That Almost Works

A tiny program for the make.fun competition [The Excuse That Almost Works](https://make.fun/c/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5).

It writes one hurried, boringly specific text-message excuse — a landlord's
plumber booked into an 8–12 window, with three weeks of cold showers as the
price of missing him — to `/output/entry.txt`. No dead grandmother, no flat
tyre, no sudden fever: just a tradesman's time slot nobody would invent.

Run it with:

```sh
python3 main.py
```
